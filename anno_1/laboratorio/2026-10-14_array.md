# Array

Un **Array** e' una struttura dati che permette di memorizzare una sequenza ordinata di elementi. In TypeScript, un array di $n$ elementi possiede indici numerici interi che vanno da $0$ a $n-1$.

* **L'ordine degli elementi conta**: 
  $$\text{Ad esempio: } [1, 2, 2] \neq [2, 1, 2]$$

* **Esempio di indice e elementi**:
  | Indice | 0 | 1 | 2 | 3 | 4 | 5 |
  | :--- | :---: | :---: | :---: | :---: | :---: | :---: |
  | **Elemento** | $2$ | $5$ | $8$ | $9$ | $4$ | $3$ |

* **Dichiarazione**:
  ```typescript
  let arr: number[] = [2, 10, 3, 4, 1];
  ```

---

## Tipologie di Array

### Array Omogenei
Un array **omogeneo** contiene elementi tutti dello stesso tipo $T$.
* **Array normale**:
  ```typescript
  let a: number[] = [5, 4];
  ```
* **Array vuoto**:
  ```typescript
  let a: number[] = [];
  ```

### Tupla (Array non omogenei)
Il tipo **Tupla** permette di definire un array con un numero fisso di elementi i cui tipi sono noti in anticipo e possono essere diversi tra loro.
```typescript
let coppia: [string, number] = ["a", 4];
```

---

## Accesso e Operazioni Base

* **Accesso agli elementi**: Si effettua tramite indice $\rightarrow$ `arr[i]`
* **Lunghezza dell'array**: Si ottiene tramite la proprieta' $\rightarrow$ `arr.length`
* **Attenzione**: Accedere a una posizione inesistente restituisce `undefined`

---

## Array di Array (Array Bidimensionali)
E' possibile creare strutture dati multidimensionali, come un array di array (matrici).

```typescript
let x: number[][];
x = [[3, 5], [2, 1], [7, 9]];
```

---

## Metodi Principali degli Array

Ecco un riepilogo dei metodi piu' comuni per manipolare gli array in TypeScript:

* **`a.push(z)`**: Aggiunge l'elemento $z$ in coda all'array.
* **`a.pop()`**: Rimuove l'ultimo elemento dall'array.
* **`a.shift()`**: Rimuove il primo elemento dall'array.
* **`a.concat(b)`**: Crea un nuovo array concatenando l'array $b$ in coda all'array $a$.
* **`a.sort()`**: Ordina gli elementi dell'array in modo lessicografico (particolarmente utile ed efficace sulle stringhe).
